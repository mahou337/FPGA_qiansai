# HDMI 与机械手联调（2026-11-02）

本次仅新增启动入口，不改变原delivery、启动镜像、rootfs、机械手端点、速度或保护逻辑。
启动器沿用原start_follow.py的文件校验、TTY现场FOLLOW_FINAL确认及运行锁，只额外开启--hdmi --hdmi-hz 5。
原无机械手HDMI入口继续保留。新入口不会开机自动启动。

## 上电与启动

开发板断电插卡，使用原已验证的接线与供电。机械手固定、空载，人员远离活动区域，准备物理断电开关。
停掉其他识别/诊断程序。确认此次开机已加载显示驱动；未加载时：

```sh
base=/mnt/sdcard/hdmi_linux_integration_20261102
ls -l /dev/gesture-mask-display
```

若节点不存在，执行一次并确认节点创建成功：

```sh
insmod "$base/candidate/gesture_mask_display.ko"
ls -l /dev/gesture-mask-display
```

加载失败就停止，不启动机械手联动。

```sh
sh "$base/run_hdmi_follow.sh"
```

看到提示后单独手动输入FOLLOW_FINAL再回车；空行不授权，超时取消，不要管道输入确认词。
确认后会打开机械手UART并运行原预检和控制流程。不能把五指身份参考阶段当作绝对无动作状态。
原控制策略可能根据单帧完整raw更新目标，PENDING也可能动作；本次没有添加新的稳定帧门槛。
显示故障沿用原旁路隔离设计，不保证停止机械手；显示消失不能视为机械手已停。

## 保留参数

- IDS: 1..8；拇指(7,8)、食指(1,2)、中指(3,4)、无名指(5,6)。
- OPEN按ID顺序：584,404,418,602,439,576,440,582。
- CLOSED按ID顺序：206,769,90,989,128,895,195,864。
- MaxSpeed参数5 rad/s（raw 977），不是实测速度；未降低或提高。
- 反馈裕量15 raw；软件电压窗口4.5..7.6V，不是建议调整供电的范围。
- 原hand_final/hand_policy/hand_bus/hand_worker及停止保护保持不变，不重新标定端点。

## 停止

Q或Ctrl+C请求退出及扭矩释放。若卡死、异常持续用力或提示RELEASE_NOT_CONFIRMED/CUT SERVO POWER，立即切断舵机电源，不用手阻挡。
结束后先确认舵机状态，再在Linux执行sync和poweroff，等待关机停止后切断板电源并拔卡；不要运行中直接拔卡。
